# v0.4.7 Light Notes

v0.4.7 brings Hermes Agent into the supported MidBrain client set, makes
automatic repair safe across temporary and cached runtime paths, and installs
proactive memory-first rules across Codex, OpenCode, Claude Code, Hermes, and
NanoClaw.

Hermes support includes active YAML MCP configuration, project scoping,
stable user/assistant capture hooks, installer integration, credential
fallback, and gateway restart guidance.

Self-repair now writes only canonical stable shims and
`midbrain-memory-mcp@latest`, never a disposable worktree, `/private/tmp`, or
npx-cache path. Exact hook ownership, closed-list OpenCode cleanup, marked
development-state preservation, and content-compared writes protect custom
configuration and avoid approval-breaking mtime churn.

The installer also writes a compact managed MidBrain rules block to the global
and project instruction surfaces used by each detected client. Client-specific
tool-loading adapters are documented, safe recognized-block migration preserves
custom or uncertain hardening, and `--no-rules` remains supported.

Live validation found some prompt-sensitive exact-retrieval variance in noisy
memory corpora; follow-up rule hardening is planned. MCP loading, capture,
installer correctness, and configuration safety are unaffected.

Breaking changes: none.
