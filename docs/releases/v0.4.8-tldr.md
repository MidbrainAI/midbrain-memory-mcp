# v0.4.8 TLDR

- Restores NanoClaw episodic capture silently broken by v0.4.7's hook
  migration; broken installs self-heal on the first fresh container.
- Persists the MCP server's environment key to the global key file at startup
  (absence-only, guarded) so env-less hook children can authenticate.
- Routes every credential write through one guarded atomic writer and stops
  cross-scope credential promotion.
- Unifies API-host resolution between the MCP server and capture hooks.
- Adds an account keystore and a `memory_diagnostics` tool.
- Adds an opt-in capture-client marker so NanoClaw captures label as
  `nanoclaw`.
- Breaking changes: none.
