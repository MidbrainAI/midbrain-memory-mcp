# v0.4.9 TLDR

- Makes existing and new NanoClaw groups capture as `nanoclaw` without
  relabeling ordinary Claude Code hosts.
- Preserves the opening user message and completed assistant response on a
  cold NanoClaw wake through durable state, bounded key resolution, and a
  binding-scoped recovery spool.
- Drains failed episodic captures once per boot with bounded, paced,
  binding-scoped, WAF-aware recovery instead of replaying on every hook.
- Adds privacy-normalized `cwd` and verbatim nonblank `session_id` metadata to
  captures across all five supported clients.
- Adds `X-Midbrain-User-Agent` with package version and resolved client
  identity across authenticated API requests.
- Breaking changes: none.
